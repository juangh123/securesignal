## v2 (2026-08-04) ? Polished cut

Deliverable: `video/dist/SecureSignal_demo_1080p_v2.mp4` (2:18.9, 1080p30, H.264 + AAC, ~14.5 MB, -16 LUFS)

### What changed in v2
- **Scenes rebuilt** (`video/scenes/segN_*.html`) with a shared motion library
  (`video/assets/html/v2_common.js` + `v2_common.css`): particle network background,
  radar sweep, scanlines + vignette, count-up numbers, animated check-marks, and
  SpaceGrotesk typography (`video/assets/fonts/SpaceGrotesk-Variable.ttf`).
- **Transitions**: segments are joined with ffmpeg `xfade` (fade / smoothup / smoothleft)
  instead of hard cuts; timeline is 138.9 s total.
- **Sound design**: procedural SFX (`video/scripts/gen_sfx.py` ? `video/raw/sfx/`)
  ? whooshes on scene changes, pops for threat badges, sub-boom on the "Not even we can
  see your data" punch, shimmer on result reveal, verification chime, UI ticks/clicks.
  BGM is ducked under the voiceover via `sidechaincompress`.
- **Subtitles**: re-timed to the new timeline (`video/subs/combined.srt`, 49 cues),
  rendered by libass via DirectWrite with Segoe UI Bold + translucent box.

### Assets & licenses
- SpaceGrotesk font: OFL 1.1, from `google/fonts` (`raw.githubusercontent.com/google/fonts/main/ofl/spacegrotesk/`).
- Voiceover: edge-tts `en-US-AndrewNeural`, rate -8% (unchanged from v1).
- BGM: unchanged from v1 (`video/raw/bgm.wav`).
- SFX: procedurally synthesized in `video/scripts/gen_sfx.py` (no external samples).
- Honest note: seg2/seg4/seg5 visuals are **dev-simulated UI scenes**; the numbers/data
  come from the real e2e run (`frontend/e2e/e2e-local-run.log`, 23/23 green) and are
  labeled on-screen as such. To replace with real screen recordings, see the v1 workflow
  at the top of this file.
